# JavaScript 2 Course Assignment

Front-end social media application built with vanilla JavaScript and the Noroff Social API.

# Description

This project was created as part of the JavaScript 2 Course Assignment at Noroff.

The application allows registered users to log in and interact with a social media feed. Users can create, edit and delete their own posts, view other users' profiles and posts, follow and unfollow users, and search through posts.

The project uses ES6 modules and the Noroff Social API.

## Features

- Register a new user

- Login and logout

- View all posts

- View a single post

- Create a post

- Edit own posts

- Delete own posts

- Search posts

- View user profiles and their posts

- Follow and unfollow users

- View own profile

## Built With

- HTML

- CSS

- JavaScript

- Noroff Social API

## Getting Started

### Clone the repository

git clone https://github.com/stigjoran/js2-course-assignment.git

### Install

No installation or dependencies are required.

### Run locally

Open the project in VS Code and run it using Live Server.

Start from:

index.html

You will need a registered Noroff user account to log in and use the authenticated features of the application.
